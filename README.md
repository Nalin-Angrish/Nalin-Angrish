# Hi 👋, I'm Nalin Angrish

**Systems software built close to the metal, with zero room for failure.**

I'm a systems software engineer working across low-latency distributed systems, autonomous cloud and datacenter operations, and real-time robotics. I care about the architectural decisions that don't show up in the diff but determine whether a system holds together under pressure.

- **Most recently:** SDE Intern at **Nava** — worked on the intelligence platform for autonomous cloud and datacenter operations: Graph-RAG retrieval, an agentic reasoning harness, GPU-cluster simulation for LLM inference, and observability pipelines.
- **Previously:** Research Intern at **IISc Bengaluru (RBCCPS, FOCAS Lab)** — built distributed real-time control for multi-UAV swarms on ROS2, including a Control Barrier Function safety layer for collision avoidance and geofencing.
- **Education:** B.Tech at **IIT Ropar** ('23–'27).
- **Leadership:** Previously Secretary of the Aeromodelling Club and Software Community Representative at IIT Ropar, and Deputy Contingent Leader for Inter IIT Tech Meet 14.0.
- **Open to:** high-impact systems engineering roles and collaborations.

## 🚀 What I work on

- **Systems & infrastructure** — C++ daemons, Unix IPC, Linux runtime internals, GPU memory enforcement with NVML, systemd
- **Cloud & distributed systems** — Go/Python services, gRPC, Graph-RAG, agentic reasoning harnesses, observability pipelines
- **AI infrastructure** — GPU-cluster simulation, vLLM/SGLang inference configs, local LLM tooling, MCP
- **Robotics & control** — ROS2, PX4/MAVLink, Control Barrier Functions, fault-tolerant flight, multi-UAV swarms
